# OSPF Single Area Configuration

## Objective
This lab focuses on the configuration of OSPF within a single area (Area 0 by default)

## Tools Used
- Cisco Packet Tracer 8.2.2


## Lab Tasks
1. Assigned IP Addresses to all interfaces in the network
2. Set Password to access the global configuration of switches and routers
3. Configured Telnet on the switches and routers
4. Set up OSPF Single area on the routers
