# Cisco Packet Tracer Labs

A growing collection of Cisco Packet Tracer labs completed as part of my 
networking studies. 
Each lab folder contains the `.pkt` files and configuration 
screenshots.

## Labs

| # | Lab | Topics Covered |
|---|-----|----------------|
| 01 | [Cisco Routers and Switches Config](./Lab01-Basic Config/) | IP Addressing, Router and Switches Configuration |
| 02 | [OSPF-Single Area Config] (./Lab02-OSPF_Single Area/) | OSPF Configuration | 
| 03 | [OSPF-Multi Area Config] (./Lab03 - OSPF_Multi Area/) | IPV4 & IPV6 OSPF Configuration for Multi Area |
| 04 | [ACL & NAT Config] (./Lab04 - ACL & NAT/) | Types of ACL configs and NAT types |
| 05 | [Etherchannels and EIGRP Configuration] (./Lab05 - Etherchannels & EIGRP/) | LACP, PAgp, EIGRP |

## Tools
- Cisco Packet Tracer 9.0.0
